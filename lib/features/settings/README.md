Settings feature

Files:
- domain/user.dart: simple UserProfile model
- data/mock_settings_repository.dart: mock loader for profile
- providers.dart: Riverpod providers for repo and user
- ui/settings_page.dart: a ConsumerWidget that shows the settings UI
- ui/widgets/account_header.dart: header with avatar and name
- ui/widgets/settings_item.dart: simple list tile for settings entries

Usage:
- Navigate to SettingsPage or add it to your app navigation to preview.
